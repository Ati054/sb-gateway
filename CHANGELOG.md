# Changelog

## 1.6.32

- Исправлен преждевременный откат Apply с крупной GeoIP-базой: запуск Xray
  и проверка готовности учитывают время компиляции маршрутов, в том числе
  при восстановлении предыдущей конфигурации.
- Аварийный поиск резерва после подтверждённого отказа больше не прерывается
  фоновой проверкой другого маршрутного листа. Результат старого поколения
  runtime отклоняется до переключения после нового Apply.
