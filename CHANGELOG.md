# Changelog

## 1.6.35

Изменения относительно публичной 1.6.34.

- Добавлено переключение при подтверждённой просадке собственной скорости активного узла. В URLTest пороги просадки и выигрыша независимы и расположены рядом; в режиме «Приоритет + резерв» есть только порог просадки, 0 отключает такой выход.
- При просадке URLTest сначала сравнивает резервы свежими парными замерами и подтверждает выбранного претендента, чтобы не переходить через промежуточный более медленный узел. В приоритетном режиме сохраняется порядок очереди, чужой выигрыш скорости сам по себе не меняет маршрут.
- Недавно просевшие узлы временно исключаются из планового возврата; одиночный всплеск скорости не отменяет защиту. Аварийный поиск работающего маршрута сохраняется.
- Скоростные замеры связаны с существующими интервалами качества без нового поля настройки: стандартно активный узел каждые 3 минуты, рабочие резервы каждые 15 минут, вне рабочего пула — медленный полный обход. Подтверждения и общий бюджет могут увеличивать фактическое ожидание.
- Авто использует 5 одновременных HTTPS-проверок и рабочий пул из 5 узлов. Все листы делят общий бюджет уникальных серверов, свежие проверки пересекающихся узлов не дублируются. Сохранённые значения не перезаписываются, ручной выбор остаётся доступным; скоростные скачивания выполняются последовательно.
- Ошибки подготовки служебного селектора Xray не записываются как отказ VPN-узла. Число параллельных фоновых API-команд ограничено, прерванные проверки повторяются без ложного ухудшения здоровья маршрута.
