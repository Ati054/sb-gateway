# SB Gateway 1.6.44

Изменения относительно публичной 1.6.35:

- URLTest выбирает узлы по HTTPS-задержке без скачиваний для замера скорости. Удалены скоростные настройки, накопительные штрафы, пауза возврата 600 секунд и P95.
- В мониторинге оставлены интервал доступности, интервал оценки задержки и числовой лимит параллельных проверок 1–64. По умолчанию — 10; общие узлы листов не проверяются повторно.
- Плановый переход URLTest требует настроенного выигрыша в миллисекундах и двух свежих подтверждений. При запуске порог не мешает первоначальному выбору; исправный сохранённый узел восстанавливается после перезапуска. «Приоритет + резерв» соблюдает порядок пользователя.
- Ускорен аварийный поиск в обоих режимах: обход больших списков не начинается заново, свежий рабочий резерв принимается без ожидания медленных соседей. Сигналы Xray имеют приоритет, результат переключения сверяется с ядром.
- Таблица качества сортируется по медиане периода, включая активный узел. «Delta, %» показывает разницу по свежим HTTPS-пробам, ошибки HTTPS не называются потерями пакетов. Исправлены флаги и размещение настроек.
- Исправлены тайм-аут добавления обработчика Xray, горячее обновление и восстановление выбора. Повреждённые записи ACME не вызывают повторный заказ; ошибки планировщика записываются. Сервисы собраны на Go 1.27.1.

Changes since public 1.6.35:

- HTTPS-latency URLTest replaces download-based speed selection. Speed settings, accumulated penalties, the 600-second return pause and P95 have been removed.
- Monitoring now exposes availability interval, latency interval and numeric concurrency from 1 to 64, defaulting to 10. Shared nodes across lists reuse probe results.
- Planned URLTest changes require the configured millisecond advantage and two fresh confirmations. Initial selection is not constrained by that threshold; healthy saved selections survive restart. Priority mode preserves the user's order.
- Both modes retain progress through large outage lists and accept a fresh working reserve without waiting for slow neighbours. Xray failure signals take precedence, and selection is verified against the core.
- Quality rows, including the active node, are sorted by the period median. “Delta, %” compares fresh HTTPS samples; failed HTTPS checks are no longer labelled packet loss. Flags and setting layout have been corrected.
- Xray handler-add timeout handling, hot refresh and selection restoration have been corrected. Corrupt ACME records do not create repeat orders, scheduler errors are logged, and services use Go 1.27.1.
