# SB Gateway 1.6.78

- Share cached policy DNS answers and pending lookups between client lanes only after each lane permits the query and selects the same DNS server route.
- Preserve isolation between resolver profiles and detours, including WAN and VLESS. A shared resolver address alone does not permit sharing.
- Keep complete DNS request options in the key, restore each client's transaction ID, and start each new DNS runtime with empty caches.

DNS worker counts, queue bounds, cache limits, request timeouts, the Xray core
version and existing container memory limits are unchanged.
