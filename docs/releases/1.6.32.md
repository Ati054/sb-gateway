# SB Gateway 1.6.32

## Русский

- Исправлен откат при применении настроек с большой GeoIP-базой, в том числе
  GeoIP RU в нескольких маршрутных листах. Xray получает достаточно времени
  для загрузки маршрутов; применение завершается сразу после готовности.
- Восстановление предыдущей конфигурации также учитывает длительный запуск
  Xray с GeoIP.

Для обновления загрузите `sb-gateway-1.6.32-linux-arm64.tar` в разделе
**Эксплуатация → Обновление контейнера**. Для новой установки используйте
`sb-gateway-1.6.32-routeros-bundle.zip`.

## English

- Fixed premature rollback when applying a large GeoIP database, including
  GeoIP RU in multiple routing policies. Xray has time to load its routes;
  Apply finishes as soon as the runtime is ready.
- Restoring the previous configuration also allows for Xray startup with GeoIP.

For an update, upload `sb-gateway-1.6.32-linux-arm64.tar` under **Operations →
Container update**. For a new installation, use
`sb-gateway-1.6.32-routeros-bundle.zip`.
