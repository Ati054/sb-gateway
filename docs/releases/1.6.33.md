# SB Gateway 1.6.33

Снятые сборки 1.6.31/1.6.32 не переиздаются.

## Русский

Изменения относительно публичного [SB Gateway 1.6.27](https://github.com/Ati054/sb-gateway/releases/tag/v1.6.27).

### Ядро и соединения

- Серверный Xray-core обновлён с 26.9.9 до [26.9.30](https://github.com/XTLS/Xray-core/releases/tag/v26.9.30),
  exact commit `b26a91de4f3294e26a0ad0a970b81a386a41f789`.
  Upstream помечает эту версию prerelease. В неё входят обновлённый FinalMask,
  снижение памяти GeoSite matchers, исправления Hysteria UDP/UDP hopping,
  HTTPUpgrade headers и Vision direct-copy CloseNotify.
- Локальные compatibility patches перенесены с учётом нового FinalMask TCP dial
  path. Зависшее установление XHTTP/TCP ограничено тайм-аутом без закрытия
  уже открытых соединений. REALITY dependency остаётся на прежнем exact pin.
- Routing reload сохраняет selector override и согласован с конкурентным
  переключением. Экспортируемый Reverse bridge пока закреплён на 26.7.28;
  RAW/XHTTP/gRPC совместимость с новым серверным ядром подтверждена напрямую.
- Исправлены обнаруженные race detector гонки selector cache, раннего отказа
  XHTTP и TLS certificate/OCSP refresh. Обновлённый сертификат публикуется
  отдельным неизменяемым snapshot без изменения сертификата активных handshakes.

### Маршрутные листы и каталог

- Добавлены динамические группы узлов для одной или всех подписок: фильтры
  страны, протокола, имени/emoji и исключения целых слов. После refresh состав
  пересчитывается; доступны preview состава и просмотр в исходном порядке подписки.
- Добавлены правила доменов, IP/CIDR и TCP/UDP-портов/диапазонов через WAN или
  VLESS. Необязательные HTTP/TLS/QUIC-фильтры относятся к доменным/IP-правилам.
  Правила также включаются в поддерживающие их клиентские профили.
- Расширен региональный каталог, включая сервисы Китая и Ирана. Улучшена
  обработка GeoSite; новая выбранная карточка обновляется перед Apply.
  Неподдерживаемые GeoSite labels не ломают outage DNS-исключения RouterOS.
- Добавлены необязательные GeoIP country routes с ограничением размера базы,
  ручным/ежесуточным обновлением и горячей активацией без перезапуска Xray.
  При неуспешном обновлении восстанавливаются прежние активные GeoIP-правила.

### Apply, GeoIP и восстановление

- При занятой конфигурации сохранение/reset/CRUD черновика сразу возвращают
  явный конфликт без изменения данных; исключена поздняя запись после nginx 504.

- Исправлены преждевременные откаты с крупным GeoIP: готовность подтверждается
  завершённой валидацией текущего процесса, не одним открытым API-портом.
  Watchdog не запускает повторную тяжёлую компиляцию той же базы.
- Фоновый refresh не вмешивается в Apply/rollback. Изменение посторонней
  monitor-настройки не перезапускает Xray и не загружает неизменные GeoIP-правила снова.
- Горячий Apply сохраняет активный selector; после планового перезапуска и
  runtime-only Apply возвращается managed traffic gate. Watchdog не перезапускает
  контейнер во время незавершённого RouterOS rollback.
- Watchdog читает структурированный nft JSON: каноническое форматирование
  reject больше не вызывает ложный отказ исправного контейнера.

### URLTest, подписки и панель

- История узлов сохраняется при ошибке чтения состояния/перезапуске. Refresh
  подписки обновляет выбранное поколение узла без потери истории остальных узлов.
- Подтверждённые отказы отделены от плановых замеров; нестабильный узел временно
  исключается из планового возврата. После общего отказа WAN/DNS рабочий маршрут
  не меняется по устаревшей ошибке, активный узел проверяется заново.
- Аварийный поиск резерва не прерывается фоновой проверкой другого листа;
  результаты прежнего runtime generation не допускаются к переключению.
- Скрипты RouterOS согласуются с версией установленного контейнера автоматически.
  Журналы «Маршруты» и Control plane разделены, обычные probe-команды не
  засоряют RouterOS log. Предупреждение о нестабильности требует устойчивого отказа.
- Улучшены desktop/mobile редакторы листов, групп и правил. Статус refresh
  подписки различает загрузку узлов и их фактическую активацию.

### Ограничения и обновление

VLESS/Xray переносит TCP/UDP, а не произвольный IP-туннель. Публичный ICMP/ping
управляемого клиента явно отклоняется без routing loop и скрытого прямого WAN bypass.
Локальная сеть и настроенные исключения сохраняют своё отдельное поведение.
GeoIP не включается автоматически: страна выбирается явно в нужном листе.
Новые upstream MASQUE/XDRIVE/TUN-функции этой сборкой не включаются.

Для обновления с 1.6.27 загрузите `sb-gateway-1.6.33-linux-arm64.tar` в разделе
**Эксплуатация → Обновление контейнера**. Для новой установки используйте
`sb-gateway-1.6.33-routeros-bundle.zip`. Сверьте SHA-256 с `SHA256SUMS`.

## English

Changes since the public [SB Gateway 1.6.27](https://github.com/Ati054/sb-gateway/releases/tag/v1.6.27).

- Server Xray-core updated from 26.9.9 to 26.9.30 (upstream prerelease), pinned
  to `b26a91de4f3294e26a0ad0a970b81a386a41f789`. Includes the FinalMask refactor,
  lower GeoSite matcher memory use, Hysteria UDP/UDP hopping fixes,
  HTTPUpgrade headers and Vision direct-copy CloseNotify changes.
- Local compatibility and bounded transport-retirement patches adapted to the
  new FinalMask TCP dial path. Stalled XHTTP/TCP establishment is bounded without
  closing established streams; the REALITY dependency pin is unchanged.
- Routing reload retains selector overrides and is serialized with switching.
  Exported Reverse bridges remain pinned to 26.7.28, with direct RAW/XHTTP/gRPC
  compatibility confirmed against the new server core.
- Fixed race-detector findings in selector cache replacement, failed XHTTP setup,
  and TLS certificate/OCSP refresh. Refresh publishes an immutable certificate
  snapshot without changing the certificate used by active handshakes.
- Dynamic subscription node groups support one/all feeds, country, protocol,
  name/emoji matching and whole-word exclusions, with membership preview,
  refreshed membership and original subscription order.
- Custom domain, IP/CIDR and TCP/UDP port/range rules select WAN or VLESS.
  Optional HTTP/TLS/QUIC filters apply to domain/IP rules; supported client profiles
  include the corresponding rules.
- Expanded regional service catalog, including China and Iran; improved GeoSite
  matching and refresh of newly selected cards before Apply. Unsupported GeoSite
  labels no longer break RouterOS outage DNS exceptions.
- Opt-in bounded GeoIP country routes support manual/daily refresh, hot activation
  without restarting Xray and restoration of previous rules on failed updates.
- Large GeoIP Apply waits for completed validation of the current Xray process,
  not just an open API port. Watchdog avoids recompiling the same database.
- Draft save/reset/CRUD returns an immediate explicit conflict while configuration
  is busy, without changing data or writing after a management proxy timeout.
- Background GeoIP refresh is deferred throughout Apply/rollback; unrelated
  monitor-setting changes do not restart Xray or reload unchanged GeoIP rules.
- Hot policy Apply retains the active selector. Planned restarts/runtime-only
  Apply restore the managed traffic gate; watchdog respects pending RouterOS rollback.
- Structured nft JSON readiness avoids false watchdog failures caused by reject
  statement formatting.
- Node history survives state-read errors/restarts. Subscription refresh updates
  the selected node generation while retaining other nodes' history.
- Confirmed failures are separated from scheduled measurements; unstable nodes
  are temporarily excluded from planned returns. WAN/DNS recovery requires fresh
  active-node evidence instead of switching on an old failure.
- Emergency recovery is not interrupted by another policy's background probe;
  stale runtime-generation results cannot trigger a switch.
- Installed RouterOS scripts reconcile automatically with the container version.
  Route and Control plane logs are separated; routine probes no longer fill the
  RouterOS log, and unstable-route warnings require sustained failure.
- Improved desktop/mobile policy, group and custom-route editors. Subscription
  refresh distinguishes downloaded inventory from runtime activation.

VLESS/Xray carries TCP/UDP, not arbitrary IP traffic. Managed public ICMP/ping
is explicitly rejected without a routing loop or silent direct-WAN bypass.
Local-network exceptions retain their separate behavior. GeoIP is opt-in;
new upstream MASQUE/XDRIVE/TUN features are not enabled by this release.

To update from 1.6.27, upload `sb-gateway-1.6.33-linux-arm64.tar` under
**Operations → Container update**. For a new installation use
`sb-gateway-1.6.33-routeros-bundle.zip`. Verify the archive against `SHA256SUMS`.
