# SB Gateway 1.6.58

- WAN ping switch for managed IPv4/IPv6 clients, enabled by default. Related ICMP errors always pass; multicast and broadcast survive removal from editable exclusions. Other public IP protocols are blocked. Legacy rollback preserves the RouterOS import contract.
- Watchdog no longer repeats Xray configuration tests. Check/Apply, startup checks and transactional GeoIP validation/rollback remain active.
- Reverse status uses online telemetry, name editing preserves focus, and startup waits up to 30 seconds for a selected working Reverse. Profiles stay independent; blocked internal tunnels are avoided without terminating streams.
- Five-second HTTPS availability rounds, additional sites after two seconds, fresh-measurement URLTest failover and cleanup of stalled REALITY probe sockets.
- ACME issuance for inactive profiles and queued-request preservation across unchanged saves. Interrupted issuance still requires explicit retry.
- Architecture-default Xray buffers. After upgrading, run Apply once to reconcile settings and RouterOS rules. Managed LAN IPv6 TCP/UDP proxying is not added.
