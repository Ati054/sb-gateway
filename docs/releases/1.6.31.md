# SB Gateway 1.6.31

## Русский



Для обновления загрузите `sb-gateway-1.6.31-linux-arm64.tar` в разделе
**Эксплуатация → Обновление контейнера**. Для новой установки используйте
`sb-gateway-1.6.31-routeros-bundle.zip`.

## English

- Rule-based node groups can span one or all subscriptions and match country,
  protocol, name fragments or emoji while excluding specified whole words.
  Membership changes are previewed; subscription order is available.
- Custom domain, IP and TCP/UDP port routes target WAN or VLESS, with optional
  HTTP/TLS/QUIC filters for domain and IP rules. Regional cards and GeoIP can
  be combined with GeoSite.
- Active GeoIP data refreshes daily or manually and updates Xray routing
  without a restart, preserving the selected node. There is no 30-second
  GeoIP poll; reverting a database change also updates the live route.
- Image update with active GeoIP and both routing directions passed on an
  isolated CHR. The physical hAP was not tested in this run.

For an update, upload `sb-gateway-1.6.31-linux-arm64.tar` under **Operations →
Container update**. For a new installation, use
`sb-gateway-1.6.31-routeros-bundle.zip`.
