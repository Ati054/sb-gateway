# SB Gateway 1.6.27

## Русский

- Убраны ложные переключения и задержки при выборе рабочего резерва.
- URLTest повторяет неудачный замер скорости и быстрее уходит с медленного узла.
- Уменьшено накопление памяти при обновлении подписок без разрыва открытых соединений.

Для обновления загрузите `sb-gateway-1.6.27-linux-arm64.tar` в разделе
**Эксплуатация → Обновление контейнера**. Для новой установки используйте
`sb-gateway-1.6.27-routeros-bundle.zip`.

## English

- Fixed false route switches and delays when choosing a working backup node.
- URLTest retries failed speed measurements and leaves a slow node sooner.
- Reduced memory buildup during subscription updates without dropping open connections.

To update, upload `sb-gateway-1.6.27-linux-arm64.tar` under **Operations →
Container update**. For a new installation, use
`sb-gateway-1.6.27-routeros-bundle.zip`.
