# SB Gateway 1.6.94

URLTest: Исправлены ошибки, улучшена стабильность.

### DNS и подписки

- DNS управляемых IPv4-клиентов поступает непосредственно в контроллер с сохранением назначенных правил.
- После подтверждённой смены маршрута DNS использует отдельное состояние подключения.
- Подписки сохраняются целиком без усечения каталога.
- Улучшены запуск, обновление данных подписок и подготовка совместимого отката.
- Исправлено применение изменившихся параметров узлов подписок.

### Ядро и панель

- Серверное ядро обновлено до Xray 26.10.31.
- Сокращена повторная обработка истории проверок при запросах панели.
- Региональные карточки показаны перед карточками умного дома.

После установки откройте панель и выполните «Применить обновление», если она предлагает обновить правила. Это подключает новые правила DNS для управляемых IPv4-клиентов.

Сохранённые настройки и лимиты памяти сохраняются.
