# SB Gateway 1.6.79

### URLTest

Исправлены ошибки, улучшена стабильность.

### DNS

- Уменьшен расход памяти на повторяющиеся DNS-политики и ожидающие запросы.
- Совместимые одинаковые запросы объединяются до занятия рабочего слота.
- Рабочие слоты и очереди распределяются между профилями резолверов, чтобы один медленный путь не занимал весь допуск службы.
- По умолчанию используются 32 общих слота DNS. Сохранённые пользовательские ограничения, маршруты резолверов и лимиты памяти контейнера сохраняются.
